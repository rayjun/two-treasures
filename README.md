# 两个人的宝藏

温柔绘本花园风格的双人合作网页游戏，当前为 v0.3 沉浸版。

## 游玩

使用电脑浏览器打开 GitHub Pages 站点。游戏为同一台电脑双人同屏；不是远程联网对战。无需登录、安装或第三方资源。

- 支持两个人共用键盘，也提供自动同行者用于单人试玩。
- 包含小屋、森林、合作机关、树怪 Boss、宝箱、回家种树和纪念册。
- 操作说明会随移动、接近物件及战斗状态在游戏中出现。
- 按 Esc 或画面右下角暂停按钮，可查看手册、调整声音、全屏和导出/导入存档。
- 进度保存在当前浏览器，不上传游戏数据。更换网址或设备时请导出/导入存档。
- 手机仅作画面预览，完整操作需要键盘或手柄。

## 部署

此仓库仅存放已构建的游戏成品 `index.html`。所有背景图、界面和逻辑均内嵌在文件内，GitHub Pages 从 `main` 分支根目录发布。

更新时替换 `index.html` 并提交到 `main`。不需要常驻服务器或临时隧道。

场景包含生成式图像，人物和交互物由程序绘制；不使用《星露谷物语》的原素材、地图或音乐。
